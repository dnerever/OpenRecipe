title: Miso Soup
description: Never boil the miso.
yield: { count: 2, unit: bowl }
time: { prep: 5m, cook: 10m, total: 15m }
ingredients:
  - { qty: 500, unit: ml, item: dashi }
  - { qty: 2, unit: tbsp, item: white miso }
  - { qty: 150, unit: g, item: silken tofu, note: cubed }
  - { qty: 2, unit: g, item: dried wakame }
  - { qty: 1, unit: ea, item: spring onion, note: sliced thin }
tags: [soup, japanese, quick]
---

Rehydrate the wakame in cold water for 5 minutes, then drain.

Warm the dashi to just below a simmer. Add the tofu and wakame and heat through.

Slake the miso with a ladle of the hot dashi in a small bowl, then stir it back
in off the heat. Scatter the spring onion over and serve immediately.
