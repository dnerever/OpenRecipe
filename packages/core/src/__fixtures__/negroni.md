ingredients:
  - { qty: 30, unit: ml, item: London dry gin }
  - { qty: 30, unit: ml, item: Campari }
  - { qty: 30, unit: ml, item: sweet vermouth }
  - { qty: 1, unit: ea, item: orange peel }
equipment: [mixing glass, bar spoon, rocks glass]
tags: [cocktail, aperitivo]
---

Combine the gin, Campari and vermouth in a mixing glass with plenty of ice.

Stir for about 20 seconds, until the outside of the glass frosts.

Strain over a large cube in a rocks glass. Express the orange peel over the
surface and drop it in.
