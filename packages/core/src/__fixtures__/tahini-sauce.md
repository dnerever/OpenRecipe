title: Tahini Sauce
description: It seizes before it loosens. Keep going.
yield: { count: 300, unit: ml }
time: { prep: 5m, total: 5m }
ingredients:
  - { qty: 150, unit: g, item: tahini }
  - { qty: 60, unit: ml, item: lemon juice }
  - { qty: 1, unit: clove, item: garlic, note: grated }
  - { qty: 120, unit: ml, item: ice water }
  - { qty: null, item: salt, note: to taste }
  - { qty: null, item: cumin, note: "optional, a pinch" }
tags: [sauce, condiment, vegan]
---

Whisk the tahini with the lemon juice and garlic. It will thicken into a paste
that looks broken.

Add the ice water a splash at a time, whisking hard. It will loosen suddenly and
turn pale and pourable.

Season with salt and cumin. Thin further with water to whatever consistency you
need.
