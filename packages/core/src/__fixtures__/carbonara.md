  - { qty: 200, unit: g, item: spaghetti }
  - { qty: 100, unit: g, item: guanciale, note: cut into lardons }
  - { qty: 2, unit: ea, item: egg yolks }
  - { qty: 1, unit: ea, item: whole egg }
  - { qty: 50, unit: g, item: pecorino romano, note: finely grated }
  - { qty: null, item: black pepper, note: "coarsely cracked, to taste" }
tags: [pasta, italian, quick]

1. Render the guanciale in a cold, dry pan over medium heat until the fat is
   clear and the meat is crisp. Kill the heat.
2. Whisk the yolks, whole egg and pecorino into a thick paste. Add a heavy hand
   of black pepper.
3. Boil the spaghetti in well-salted water until just shy of al dente. Reserve a
   mug of the water.
4. Toss the pasta into the guanciale pan off the heat. Add a splash of pasta
   water, then the egg mixture, stirring constantly.
5. Return to the barest heat for a few seconds at a time until the sauce is
   glossy and coats the strands. It should never scramble.
