description: Overcook the chickpeas. That is the whole secret.

  - { qty: 250, unit: g, item: dried chickpeas, note: soaked overnight }
  - { qty: 1, unit: tsp, item: baking soda }
  - { qty: 150, unit: g, item: tahini, note: well stirred }
  - { qty: 60, unit: ml, item: lemon juice }
  - { qty: 2, unit: clove, item: garlic }
  - { qty: 60, unit: ml, item: ice water }
  - { qty: null, item: salt, note: to taste }
  - { qty: null, item: olive oil, note: to finish }
tags: [dip, levantine, vegan]
---

Drain the soaked chickpeas, cover with fresh water and add the baking soda.
Simmer 45-60 minutes until they smear between your fingers with no resistance.

Blitz the garlic with the lemon juice and a pinch of salt, then let it sit 10
minutes and strain out the solids. This takes the raw bite off.

Blend the hot chickpeas with the tahini and lemon-garlic liquid. With the motor
running, stream in the ice water until it turns pale and fluffy.

Rest 30 minutes before serving. Pool olive oil on top.
