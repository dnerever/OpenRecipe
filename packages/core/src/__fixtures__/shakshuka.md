  - { qty: 1, unit: ea, item: onion, note: sliced }
  - { qty: 2, unit: ea, item: red peppers, note: sliced }
  - { qty: 4, unit: clove, item: garlic }
  - { qty: 2, unit: tsp, item: cumin seeds, note: toasted and ground }
  - { qty: 1, unit: tsp, item: sweet paprika }

  - { qty: 6, unit: ea, item: eggs }
  - { qty: 100, unit: g, item: feta }
  - { qty: null, item: coriander, note: to finish }
equipment: [cast iron skillet]
tags: [breakfast, eggs, one-pan]
---

- Soften the onion and peppers in the oil over medium heat for 15 minutes. Take
  your time here; this is most of the flavour.
- Add the garlic and spices and fry until fragrant.
- Add the tomatoes, crush them with a spoon, and simmer 15 minutes until thick
  enough to hold a channel.
- Make six wells, crack in the eggs, cover, and cook 6-8 minutes until the whites
  set and the yolks do not.
- Crumble over the feta and coriander.
