  - { qty: 120, unit: ml, item: red wine vinegar }
  - { qty: 120, unit: ml, item: water }
  - { qty: 1, unit: tbsp, item: sugar }

tags: [pickles, condiment, quick]

Pack the onions into a jar.

Warm the vinegar, water, sugar and salt until dissolved. Pour over the onions
with the peppercorns.

Ready in an hour, better the next day, gone within the week.
